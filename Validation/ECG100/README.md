# 单导联 ECG 逐搏工程回归

用 MIT-BIH Arrhythmia Database 的公开记录 100（MLII）测试时间戳、候选 QRS 峰和 RR 计算。输入取自 WFDB 的固定样例，脚本核实两份输入的 Git blob 标识。将 `100.dat` 和 `100.atr` 放到同一目录后执行 `bash Validation/ECG100/check.sh 数据目录`。无需上传记录。[WFDB 固定样例](https://github.com/MIT-LCP/wfdb-python/tree/3bef000bb2b65713d86da6d57da9a94d4452aa0f/sample-data) · [数据库来源与引用](https://physionet.org/content/mitdb/1.0.0/)

本次按互不重叠的 30 秒窗口处理完整记录，最后一段取剩余采样。使用人工 N、A、V 标记作为逐搏参考，±100 ms 内一对一匹配。边界漏检和拒测窗口中的参考标记均计入漏检。RR 误差仅在同一窗口内连续配对成功的相邻两搏上计算。

| 窗口 / 拒测 | 参考搏 / 检出 | TP / FP / FN | 灵敏度 / 阳性预测值 | 峰时刻 MAE | RR 配对数 / MAE |
|---|---|---|---|---|---|
| 61 / 0 | 2273 / 2256 | 2256 / 0 / 17 | 99.25% / 100% | 1.49 ms | 2195 / 1.52 ms |

该记录属于开发期工程回归。结果仅描述此人的这一条 MLII 记录；高噪声、起搏、宽 QRS、导联倒置以及 S12 单导联的准确度和拒测率须在独立记录上验证。方法以差分活动包络定位候选 QRS，再取局部基线偏离极值；该时刻可与解剖意义上的 R 峰不同。逐搏检测本身不区分 PVC、PAC、窦性来源或缺血。经临床审核前不向用户输出实验性心律分类。
